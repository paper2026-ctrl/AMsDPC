# AMsDPC: Adaptive multi-stage density peaks clustering via core fusion and dual-tier constrained expansion.

  title={Adaptive multi-stage density peaks clustering via core fusion and dual-tier constrained expansion},
 
 Introduction={In this paper, a novel DPC variant AMsDPC is presented. An automatic core fusion is proposed and an adaptive dual-tier constrained expansion incorporating structural verification is designed. AMsDPC can eliminate manual center selection without inputting cluster counts and curbs error propagation effectively by enforcing point-level connectivity consistency and neighborhood-level structural compatibility.Through this adaptive multi stage clustering,the AMsDPC algorithm improves cluster center selection, enhances point assignment accuracy, and better handles datasets with complex structures. }
